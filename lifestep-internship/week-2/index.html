Chapter 02. Deep Learning for Computer Vision

Learning Objective

1회차에서 학습한 MLP를 바탕으로, 컴퓨터가 이미지를 입력받아 특징을 학습하고 대상을 인식하는 과정을 이해합니다. 특히 CNN이 이미지의 공간 구조를 어떻게 활용하는지, 분류·검출·분할이 어떤 문제를 해결하는지 자신의 언어로 설명하는 것을 목표로 합니다.

이미지 입력 → 전처리 → 특징 학습 → 예측 → 결과 평가

교재 범위: 2.1 OpenCV 소개 / Chapter 07 딥러닝 비전 / Chapter 08 컨볼루션 신경망 / Chapter 09 인식 중 핵심 내용. 아래 2.1–2.7은 이번 자료조사의 학습 순서입니다.

Topics

2.1 OpenCV & Image Representation

교재: 2.1 / 7.3 · 이미지 처리 기초

  • OpenCV의 역할과 TensorFlow / Keras의 역할
  • Pixel, Image Shape, Height × Width × Channels
  • Grayscale, RGB / BGR
  • Image Loading, Resizing, Normalization
  • Tensor와 Batch Dimension

이미지 한 장이 숫자 배열로 어떻게 표현되는지 설명합니다. 흑백 영상과 컬러 영상의 차원, OpenCV로 읽은 컬러 영상의 BGR 순서, 모델 입력에 필요한 전처리를 확인합니다.

2.2 From MLP to Deep Learning Vision

교재: 7.1–7.3 / 7.5–7.7 · 1회차 복습과 연결

  • Handcrafted Features vs. Learned Features
  • Supervised Learning, Input and Label
  • Training / Validation / Test Sets
  • Flatten, MLP, Softmax, Cross-Entropy
  • Training vs. Inference

MNIST 이미지를 1차원 벡터로 펼쳐 MLP에 입력하는 과정을 정리합니다. 이미지를 펼치면 픽셀 값은 남지만, 일반적인 완전연결층은 인접한 픽셀의 공간 관계를 구조적으로 활용하지 않는다는 점을 이해합니다.

학습용 데이터는 가중치 학습에, 검증용 데이터는 설정 선택에, 테스트 데이터는 최종 평가에 사용하는 이유를 설명합니다.

2.3 Convolutional Neural Networks (CNN)

교재: 8.1–8.4 · 이번 회차의 중심 주제

  • Convolution, Kernel / Filter, Feature Map
  • Local Receptive Field, Weight Sharing
  • Stride and Padding
  • ReLU and Pooling
  • Convolutional Layers → Classification Head

작은 필터가 이미지를 이동하며 특징을 추출하는 과정을 직접 그려 봅니다. MLP와 비교하여 CNN의 지역 연결과 가중치 공유가 이미지 처리에 왜 유용한지 설명합니다.

직접 확인: 5 × 5 입력에 3 × 3 필터, stride 1, padding 0을 적용했을 때 출력이 3 × 3이 되는 과정을 계산합니다.

2.4 Training & Generalization

교재: 7.6 / 8.3 / 8.6

  • SGD vs. Adam · 개념 비교
  • Learning Rate, Epoch, Batch Size · 복습
  • Training / Validation Loss and Accuracy
  • Overfitting and Generalization
  • Data Augmentation, Dropout, Early Stopping

학습 정확도만으로 모델의 성능을 판단하지 않고, 학습·검증 곡선을 함께 해석합니다. 학습 손실은 감소하지만 검증 손실은 증가하는 상황을 설명하고, 과적합을 줄일 방법을 정리합니다.

데이터 증강은 정답의 의미를 유지하는 범위에서 학습 데이터에 적용합니다. 예를 들어 숫자를 뒤집는 변환이 항상 적절한지 생각해 봅니다.

2.5 Transfer Learning

교재: 8.7 · ResNet50을 대표 사례로 조사

  • Pretrained Model and ImageNet
  • Feature Extraction and Layer Freezing
  • Replacing the Classification Head
  • Fine-tuning
  • Model-specific Input Preprocessing

이미 학습된 모델을 활용하면 새로운 과제에 필요한 데이터와 학습 부담을 어떻게 줄일 수 있는지 설명합니다. 특징 추출 방식과 미세 조정 방식에서 어떤 가중치가 학습되는지 비교합니다.

구분할 점: 사전학습된 ResNet50으로 이미지의 기존 클래스를 예측하는 것은 추론입니다. 새로운 데이터의 분류층을 학습하거나 기존 층을 미세 조정하는 전이 학습과 구분합니다.

2.6 Image Classification & Object Detection

교재: 9.1–9.3

  • Image Classification vs. Object Detection
  • Class Label, Bounding Box, Confidence Score
  • YOLO · 한 번의 전방 계산으로 검출하는 방식
  • Intersection over Union (IoU)
  • Non-Maximum Suppression (NMS)

이미지 전체의 종류를 예측하는 것과, 여러 물체의 종류·위치를 찾는 것의 차이를 설명합니다. 검출 결과에서 상자·클래스·점수가 무엇을 의미하는지 읽고, 겹치는 후보 상자를 정리하는 NMS의 목적을 이해합니다.

2.7 Image Segmentation & Applications

교재: 9.4–9.6 · 분할 개념과 사람 인식 응용

  • Pixel-wise Prediction and Segmentation Mask
  • Semantic Segmentation vs. Instance Segmentation
  • U-Net · Encoder, Decoder, Skip Connection
  • Background Replacement
  • 사람 검출과 사람 영역 분할의 활용 차이

의미 분할은 픽셀마다 클래스를 지정하고, 사례 분할은 같은 클래스에 속하는 개별 객체도 구분합니다. 여러 사람이 있는 사진을 예로 들어 두 결과의 차이를 설명합니다.

같은 사람 사진, 서로 다른 인식 결과
과제출력답하는 질문
분류이미지 단위 클래스사람이 있는 사진인가?
검출사람별 경계 상자사람이 어디에 몇 명 있는가?
의미 분할사람 클래스의 픽셀 영역어느 픽셀이 사람인가?
사례 분할사람별로 구분된 마스크어느 영역이 각각의 사람인가?

배경을 바꾸는 과제에서 경계 상자만으로 충분한지, 픽셀 단위 마스크가 왜 필요한지 설명합니다.

Selected Practice

필수 실습은 데이터 확인 → MLP와 CNN 비교에 집중합니다. 전체 프로그램을 모두 구현할 필요는 없습니다.

  1. 데이터 확인 · 프로그램 7-1
    MNIST의 이미지와 라벨을 확인하고, 데이터 shape와 픽셀 값 범위를 기록합니다. 전처리 전후의 차이를 설명합니다.
  2. MLP 기준 모델 · 프로그램 7-3
    Adam을 사용하는 MLP로 MNIST를 학습합니다. 모델 구조, 학습·검증 곡선, 테스트 정확도를 기록합니다.
  3. CNN 비교 · 프로그램 8-1
    LeNet-5 기반 MNIST 실습을 수행하고 MLP와 비교합니다. 데이터 분할·전처리·학습 조건을 가능한 한 맞추고, 실제로 다른 조건은 함께 기록합니다.

비교 항목: 입력 형태, 주요 층, 파라미터 수, 테스트 정확도, 오분류 이미지. 실행 결과를 근거로 설명하고, CNN이 반드시 더 좋다는 결론을 미리 정하지 않습니다.

선택 실습 · 하나만: 프로그램 8-6으로 사전학습 모델의 추론 결과를 확인하거나, 프로그램 9-1로 정지 영상의 검출 결과를 해석합니다.

프로그램 번호는 제공된 교재 목차 기준입니다. 교재 코드의 설치 환경과 사용 중인 라이브러리 버전을 확인하며 진행합니다.

Research Output

자료조사 결과는 다음 네 가지를 중심으로 정리합니다.

  1. 구조 비교: MLP와 CNN의 입력·연결 방식·특징 추출 과정을 그림과 짧은 설명으로 정리합니다.
  2. 학습 결과: 필수 실습의 비교표, 학습·검증 곡선, 대표 오분류 사례와 해석을 제시합니다.
  3. 인식 과제 비교: 분류·검출·의미 분할·사례 분할의 출력과 활용 사례를 구분합니다.
  4. 응용 제안: 사람 인식 또는 배경 교체 중 하나를 골라 필요한 입력, 모델의 출력, 평가 방법을 설명하고 조사한 출처를 남깁니다.

이번 회차에서 생략: 신경망의 역사와 MLP 수식 재유도, SGD·Adam 전체 비교 실험, 우편번호·견종 인식 GUI, 동영상 처리량 측정, PixelLib의 모든 예제 구현. 개념 이해와 대표 실습을 마친 뒤 확장합니다.
